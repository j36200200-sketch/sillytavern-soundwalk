# 听风 · Soundwalk Music — SillyTavern 独立音乐播放器

一个独立实现的、适合在手机浏览器和桌面 SillyTavern 中边聊天边听歌的前端扩展。**没有内置歌曲、网络曲库、商业音乐平台接口，也不提供任何未经许可的音频或图片。**

## 推荐安装（GitHub 第三方前端扩展）

1. 打开 SillyTavern → **扩展** → **安装扩展（Install Extension）**。
2. 粘贴以下公开仓库地址：

   `https://github.com/j36200200-sketch/sillytavern-soundwalk`

3. 确认安装并刷新酒馆页面，轻点黑猫按钮打开播放器。按住头像直接拖动，可放在屏幕任意不越界的位置。v1.1.0 优化了安卓触屏轻点打开逻辑。

> 这个链接需要仓库已创建且文件在仓库根目录。当前扩展不提供音源，需自行添加合法音频直链或设备上的本地音频。

## 功能

- 可自由拖动的透明猫狗头像按钮：轻点打开播放器、按住拖动不误触，并将位置保存在当前浏览器；横竖屏尺寸变化时自动保持在可见范围。
- 播放器不依赖角色卡、世界书或聊天消息。
- 播放 / 暂停、上一首 / 下一首、拖动进度、调节音量 / 静音。
- 列表循环、单曲循环、随机播放；15 / 30 / 60 分钟定时停止。
- 添加、编辑、删除合法的 **HTTP(S) 音频直链**；支持从设备选择本地音频。
- 浏览器本地保存歌曲信息；本地文件使用 IndexedDB 存储，不上传到任何服务器。
- 导出 / 导入网络音频歌单 JSON；JSON **不包含本地音频文件**，也不包含真实音频字节。

## 下载安装（Termux / 安卓本地部署）

1. 在手机浏览器下载 `soundwalk-player-v1.2.1.zip`，文件保持 ZIP 格式。
2. 在 Termux 中进入 SillyTavern 项目目录，例：`cd ~/SillyTavern`。
3. 安装 unzip：`pkg install unzip -y`。
4. 解压到当前用户扩展目录：

```sh
mkdir -p data/default-user/extensions
unzip -o ~/storage/downloads/soundwalk-player-v1.2.1.zip -d data/default-user/extensions
ls data/default-user/extensions/soundwalk-player
```

应能看到 `manifest.json index.js style.css README.md LICENSE` 等文件。重启酒馆服务并刷新浏览器页面。

> 若你启用了多用户模式，则将 `data/default-user/extensions` 替换为 `data/<用户目录>/extensions`。
> 如果 ZIP 保存到别的目录，修改 unzip 命令的 ZIP 路径。`termux-setup-storage` 可授权 Termux 访问 Android 下载目录。

## 其他设备安装

从 ZIP 解压出 **`soundwalk-player` 这个文件夹**，整个文件夹放在当前 SillyTavern 用户数据目录 `data/<user-handle>/extensions/` 下；也可按酒馆官方文档放在 `public/scripts/extensions/third-party/`，作为全用户安装的前端扩展。重启并刷新浏览器。

官方说明：https://docs.sillytavern.app/for-contributors/writing-extensions/

## 使用指南

1. 轻点黑猫图标按钮打开播放器；按住并拖动可将按钮移到屏幕任何不越界的位置，松手自动保存，下次打开酒馆仍保留。
2. 选择「+ 链接」，填入歌名与**可在浏览器直接播放**的 `.mp3`、`.m4a`、`.ogg` 等音频 HTTP(S) 地址；音乐平台的普通分享网页 URL 通常**不是**音频直链。
3. 或点击「+ 本地」，选择设备上的音频文件；本地文件存放在该浏览器的 IndexedDB，不能自动同步到其他设备。
4. 播放列表每首歌曲可以点击播放；链接歌曲可以编辑，任意歌曲可以删除。
5. 搬到另一个酒馆或浏览器时，打开「📦 备份、恢复与导入」，选择「完整备份（含音乐、封面、壁纸）」，把下载的 `.swbackup` 文件带到目标酒馆，选择「恢复完整备份」。歌曲、音频文件、封面、壁纸、角色绑定、角色顺序和设置一起迁移。恢复会替换目标播放器歌单，请先备份目标数据。
6. 「导出网络歌单」只保存网络链接歌曲和它们的绑定、顺序，不包含本地音频、图片或外观设置；只有本地歌曲时会提示使用完整备份。角色绑定按头像文件名识别，目标酒馆头像标识不同，需要重新绑定。

## 常见问题

- **按钮能看到却点不开：** 请先在酒馆扩展管理中更新到 v1.1.0 并刷新页面。如果仍无反应，可暂时停用其他浮动插件作兼容排查。
- **移动按钮：** 按住黑猫头拖动；轻点才会打开。位置保存到当前浏览器的 localStorage。

- **按钮不出现：** 检查扩展是否启用、文件夹层级是否正确、是否刷新并重启酒馆。路径应是 `.../extensions/soundwalk-player/manifest.json` 而不是双层嵌套。
- **链接歌曲不能播放：** 链接可能已失效、非直链、跨域/反盗链受限、音频编码不受浏览器支持，或浏览器阻止了未经过用户交互的自动播放。
- **切换聊天时：** 扩展属于酒馆页面的播放器，一般不会因酒馆内部切换聊天而中断。整页刷新、退出浏览器或系统后台限制可能会暂停。
- **手机锁屏后不响：** 安卓系统 / 浏览器有后台播放与电池优化限制；本扩展无法保证锁屏或后台一直播放。
- **不想使用：** 关闭扩展或删除文件夹；浏览器可能仍保留已导入本地歌曲，可在浏览器网站存储设置中清除对应站点数据。
- **歌词？** 当前版本未包含歌词服务或第三方音乐 API。

## 隐私与安全

扩展无需外部库、无需 API Key，不读取聊天记录或角色卡。只向用户输入的音频链接发起常规媒体加载请求；本地音频留在浏览器 IndexedDB。安装任何第三方扩展前，都应检查来源与代码。

## v1.1.0 · 角色歌单（新增）

- **随角色切换歌单**：进入单人角色聊天，打开「随角色切换歌单」；切换角色后自动筛选该角色绑定的曲子。旧角色正在播放、但新角色未绑定的歌曲会暂停；不会自动播放新角色歌曲。
- **绑定 / 解绑**：打开播放器 → 「管理角色绑定」，为当前角色勾选任意数量的歌曲；或直接点击曲目旁的 `♡ / ♥`。一首歌可以同时绑定多个角色。
- **关闭自动跟随**：随时关闭「随角色切换歌单」，下拉选择「全部歌曲」「未绑定歌曲」或某个角色歌单。绑定记录仍然保留，不会因为关闭自动跟随而丢失。
- **无单人角色或群聊**：自动跟随不会激活；可以手动查看全部/已有分组，但绑定需进入对应的单人角色聊天。
- **旧歌单兼容**：沿用原版 `soundwalk-player-v1` 本地存储键，原有歌名、链接、本地音频文件不会清空，初次升级旧歌曲均默认「未绑定」。
- **导出/导入**：v2 格式网络歌单 JSON 同时备份绑定信息及角色显示名称；仍兼容 v1 歌单。出于隐私，**分享歌单 JSON 前检查其中角色名称**。本地音频内容不会放进 JSON，请用户自行保留文件。绑定以当前酒馆角色的头像文件名识别，迁移到另一酒馆或重新导入角色卡后若头像标识改变，需要重新绑定。
- 本功能完全在浏览器端进行，不修改角色卡、世界书、聊天记录或 Ako 预设，不自动上传音频或角色绑定信息。

## v1.2.4 · 每首歌自定义专辑封面

- 为每首本地音频或网络音频单独设置图片：点击歌曲左侧的音符图标，或选中歌曲后点击「选择封面」，从手机相册挑选 JPG、PNG、WebP 或 GIF。
- 歌曲列表左侧显示专属小封面，顶部正在播放的歌曲同步显示大封面；随时可更换或点击「恢复默认」。
- 图片自动居中裁剪并压缩成 512×512 JPEG；封面保存在同一浏览器的 IndexedDB 新增 `covers` 仓库。数据库从 v1 升级到 v2，原有音频 `tracks` 仓库保留，不会主动删除歌曲或角色绑定。
- 重新打开浏览器、切换歌曲和角色分组仍能看到已保存封面；删除歌曲时清理对应封面。封面只保存在当前浏览器，不会随歌单 JSON 导出；跨设备或清理网站数据后需要重新选择。
- 封面文件最大支持 12MB；较大的歌单通过有限并发加载封面，减少浏览器内存占用。

## v1.3.4 · 完整备份校验与安全恢复

- 完整备份继续使用 SWBK1 的 .swbackup 文件，内置格式升级为 v3：对每个本地音频、专辑封面、壁纸计算 CRC32 校验码，对歌单和绑定等元数据也增加校验码；CRC32 用于发现意外损坏，不是防恶意篡改的数字签名。
- 备份导出阶段检查本地文件是否可读取、非空且在大小限制内，生成时分块计算校验码，防止悄悄漏掉丢失的音频或图片。

- 恢复写入本地音频、封面及壁纸使用 IndexedDB 跨 stores 单事务：写入出错时自动回滚，只有写入完成才应用新的歌单和设置。
- 以前导出的 v1/v2 完整备份仍能导入；由于老版没有校验码，会明确提示只能检查结构，不能确认文件内容。
